# 🚀 Grayson's Website 🎮

Hey there! I'm Grayson and welcome to my awesome website repository! I am super into coding, playing video games, and basically anything to do with computers. I built this whole site using HTML, CSS, and JavaScript from scratch.

👉 **Check it out live here:** [g-man124.github.io](https://g-man124.github.io)

> 🖥️ **PC GAMERS ONLY:** Leave mobile behind! This site is designed for the raw power of a real computer. Open this up on your desktop or laptop setup to load the games and tools without crashing!

---

## 🕹️ Epic Games (Play Right in Your Browser!)

*   **Super Mario 64:** Play the actual retro Nintendo game right here. No emulator download needed!
*   **Fun 2D Drive a Car:** A physics driving game. See if you can cruise around without crashing.
*   **Cool 3D Grass:** A 3D world experiment I made just to see how realistic I could make interactive grass look.

## 🛠️ My Coding Projects & Web Experiments

*   **Secret Base64 Encoder:** Send secret coded messages to your friends that nobody else can read.
*   **Cool Neon Button:** An ultra-bright glowing button experiment using custom CSS animations.
*   **The Web Store:** A mock e-commerce store layout I designed to practice layout skills.
*   **AI Caller Interface:** A custom integration concept meant for talking to AI bots.
*   **Live Camera Studio:** A media tool where you can start your webcam, record a clip, and hit save.

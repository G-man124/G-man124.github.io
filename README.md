# ⚡ Grayson's Website

Welcome to the source code for **[g-man124.github.io](https://github.io)**—a personal portfolio and interactive web playground built with HTML, CSS, and JavaScript.

## 🌐 Live Site
Check it out live here: **[https://github.io](https://github.io)**

*(Note: Some interactive features and mini-games work best on a desktop computer.)*

## ✨ What's Inside

### 🚀 Coding Projects
* **🔐 Base64 Encoder** – Encode and decode text using Base64.
* **✨ Neon Button** – A glowing CSS button showcase.
* **🛒 Web Store** – A custom web store concept.
* **🕒 Your Time** – Displays your current local time.
* **⏱ Cool Timer** – A handy timer for keeping track of time.
* **🔎 Googleify** – Turn text into something Google-like.
* **💻 Computer Code** – Explore a computer and its underlying code.

### 🛠 Interactive Tools & Games
* **🎨 Dynamic Title Color Picker** – Change the main header color on the fly.
* **🎥 Camera & Video Recorder** – Record videos directly in the browser using your webcam and download them locally.
* **🎯 Mouse Pointer Mini-Game** – Move your mouse to aim and click to create sparks.
* **📞 Call AI** – An interactive AI call demo.
* **🌐 Fullscreen Toggle & Language Selector** – Built-in UI utilities and HTML `<details>` examples.

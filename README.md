# 🎮 My Play Store

A simple app marketplace built with HTML, CSS and JavaScript.

Designed to work on **GitHub Pages** without a backend.

## Features

- 🔎 Search apps
- 🎮 App categories
- 📱 App cards
- ⬇️ Download apps
- 📤 Upload apps
- 🗑️ Delete your own apps
- 👤 Sign up
- 🔐 Login
- 🚪 Logout
- 💾 IndexedDB storage
- 📱 Responsive mobile design
- 🌐 GitHub Pages compatible
